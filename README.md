Sprite Flight - a fun and easy-to-play obstacle course game. Easy to play and visually pleasing.
How to run the project:
-Follow the link and click play.
-Open the Unity Hub, open the project, and Press Play in the Unity Editor to run the game.
Controls:
-Mouse or Touchpad(to move the sprite, to click the buttons);
-Esc the pause menu.
List of custom features:
-Main Menu;
-Pause Menu;
-High SCore Saving.
